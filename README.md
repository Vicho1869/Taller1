# Programa para ordenar alumnos y solicitudes

Este es un programa hecho en Java para organizar a los estudiantes y sus solicitudes usando la compu, sin complicarse mucho. Lee unos archivos de texto y ordena todo solito.

## De que se trata esta cosa

El programa hace lo siguiente paso a paso:
1. Lee los datos de los alumnos desde un archivo llamado Alumnos.txt.
2. Lee las solicitudes de otro archivo que se llama Solicitudes.txt.
3. Guarda todo ordenado en unas listas en la memoria del computador.
4. Crea reportes guardando en carpetas si algo no resulta o si hay solicitudes que se rechazaron.

## Que necesitas para correrlo

- Tener instalado Java en el computador.
- Un programa para abrir proyectos de Java.
- Los dos archivos de texto (Alumnos.txt y Solicitudes.txt) listos.

## Como hacerlo correr

1. Abre el eclipse en tu computador.
2. Abre la carpeta del proyecto ahi mismo.
3. Asegurate de dejar los archivos Alumnos.txt y Solicitudes.txt justo en la carpeta principal del proyecto (si no los pones ahi, el programa se marea y no lee nada).
4. Busca el archivo principal que hace funcionar todo y dale a ejecutar (play).

## Si algo falla 

- Si el programa dice que no encuentra los archivos, revisa que esten bien escritos y puestos en la carpeta que corresponde.
- Si te equivocaste escribiendo una opcion en el menu, el programa no se va a caer, solo te va a pedir que lo intentes de nuevo.
